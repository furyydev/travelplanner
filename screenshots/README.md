# Screenshots Directory

Place your app screenshots in this directory with the following naming convention:

- `login_screen.png` - Login screen screenshot
- `home_screen.png` - Home screen with search functionality
- `paris_detail.png` - Paris destination detail screen (Eiffel Tower)
- `gwalior_detail.png` - Gwalior destination detail screen (Fort)
- `saved_trips.png` - Saved trips screen

The README.md file references these images, so ensure they are named exactly as specified above.
